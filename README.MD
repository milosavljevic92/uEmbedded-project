PIC Embedded Projects Collection

A collection of small embedded electronics projects based on Microchip PIC microcontrollers.

The repository contains source code written in PICBasic Pro (versions 1.6 through 3.0) together with PCB layouts designed in Sprint Layout 5.0.

Technologies
Microchip PIC Microcontrollers
PICBasic Pro 1.6 - 3.0
Sprint Layout 5.0
Through-hole and mixed PCB designs
Supported Microcontrollers
PIC12F629
PIC16F84 / PIC16F84A
PIC16F628 / PIC16F628A
PIC18F4550
